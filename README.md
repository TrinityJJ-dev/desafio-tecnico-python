# Desafio Técnico - Resolução dos Exercícios (Python)

Este repositório contém a solução para o desafio técnico comercial, desenvolvido em **Python**.

## 📁 Estrutura do Projeto

- `dados_vendas.Json`: Base de dados de vendas do time comercial.
- `dados_estoque.Json`: Base de dados dos produtos em estoque.
- `desafio1_comissao.py`: Algoritmo que lê o JSON de vendas e calcula a comissão individual de cada vendedor conforme as regras estabelecidas.
- `desafio2_estoque.py`: Sistema de movimentação de estoque (entrada e saída) com geração de ID único e atualização em tempo real.
- `desafio3_juros.py`: Calculadora de juros por atraso baseada em data de vencimento (2.5% ao dia).

---

## 🚀 Como Executar os Programas

### Pré-requisitos
- Python 3.x instalado no computador.

### Passo a Passo

1. **Desafio 1 - Cálculo de Comissão:**
   Execute no terminal: `python desafio1_comissao.py`

2. **Desafio 2 - Movimentação de Estoque:**
   Execute no terminal: `python desafio2_estoque.py`

3. **Desafio 3 - Cálculo de Juros:**
   Execute no terminal: `python desafio3_juros.py`
